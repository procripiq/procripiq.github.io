Schemas

Timestamps in candles/funding are milliseconds UTC; trades and BBO use epoch seconds (float).

candles.parquet

timestamp, timestamp_end, coin, interval, open, high, low, close, volume, trade_count

funding.parquet

timestamp, coin, funding_rate, premium

trades.parquet

exchange, symbol, coin, trade_id, price, size, side, ts, fetched_at

bbo/exchange=<NAME>/data_0.parquet

exchange, coin, bid, ask, bid_size, ask_size, mid, mark, last, funding, ts

ticks csv.gz

ts, pair, exchange, mark, mid, bid, ask, bid_size, ask_size, last, funding, status

Quick start

Read any bundle with pandas or duckdb.

# pandas
import pandas as pd
df = pd.read_parquet("hl_candles/BTC/candles.parquet")

# duckdb — query all BBO partitions at once
import duckdb
duckdb.sql("SELECT * FROM 'bbo/exchange=*/data_0.parquet' LIMIT 5")
