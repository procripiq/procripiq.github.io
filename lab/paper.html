Rule: open when spread between A and B exceeds ±0.10%, close when it reverts below ±0.05%. Position size is $100 notional per leg. Each trade is two opposite accounts: e.g. short Coin A / long Coin B on A and long Coin A / short Coin B on B.

How to set ranges

  • Hours = how far back to look. More hours = more reliable averages, but slower to react to changes.
  • Entry = how big the spread must get before opening a trade. Higher = fewer, but stronger, signals.
  • Exit = how far the spread must revert before closing. Lower = quicker exits, but may close too early.
  • Click Suggest to use the data itself: it picks an aggressive entry (p90) and an exit near p75.
